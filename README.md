# PizzaPoint — приложение доставки пиццы

Полностью переработанная версия лабораторной работы №4. HTML, CSS и обычный JavaScript, без фреймворков и сборки. Основная навигация: Главная, Меню, Корзина, Заказы, Профиль.

## Как запустить и обновить старую версию

1. Полностью распакуйте архив.
2. Скопируйте содержимое папки lab4_pizza_pwa в C:\xampp\htdocs\pizzapoint, заменив файлы предыдущей версии.
3. В XAMPP включите Apache и откройте http://localhost/pizzapoint/.
4. Если браузер показывает старый дизайн, выполните Ctrl+F5. Service Worker обновляет собственный кеш при установке новой версии.

Для опубликованного приложения сохраните прежний адрес и замените файлы сайта. Работают HTTPS и localhost. Двойной щелчок по index.html не даёт полноценной работы Service Worker и установки PWA.

## Что изменено

- Новая кремовая палитра с графитом и томатно-красными акцентами, реальные фотографические изображения пицц, единые SVG-иконки.
- Короткая главная приложения: приветствие, адрес, предложение, категории, популярное, открывающиеся отзывы-сторис и акция с таймером до конца дня.
- Нижняя панель из пяти пунктов с выделением текущего экрана и количеством товаров.
- Меню: действующие категории, поиск по названию и ингредиентам, сортировка и избранное.
- Карточка каждой пиццы: размер 25/30/35 см, два варианта теста, добавки, количество и закреплённая кнопка с пересчётом цены. Вес также меняется. Конфигурацию можно отредактировать из корзины.
- Корзина хранит товары и их параметры, поддерживает изменение количества, удаление, скидку и бесплатную доставку от 1500 рублей. Доставка небольшого заказа — 149 рублей, самовывоз бесплатен.
- Оформление расположено в одной колонке из пяти раскрывающихся блоков. Контакты проверяются, выбранное время не может быть в прошлом.
- Заказы: четыре статуса, детали, история, повторение заказа и демонстрационное переключение этапов. После статуса «Доставлен» начисляются бонусы 3%, однократно.
- Профиль: редактирование имени, телефона и адреса, бонусы, история, избранное, настройка предложений и установка приложения.
- Схематичная карта с зонами и условиями, будущие позиции меню, сохранение интереса к запуску, офлайн-индикатор и отдельный офлайн-экран.
- Добавлены лёгкие реакции кнопок, анимация бейджа и плавные модальные окна. Учитывается prefers-reduced-motion.

## Данные и учебный режим

Сервер и база данных не подключены. Корзина, избранное, профиль, заявки и заказы сохраняются в localStorage под ключом pizzapoint.app.v2. Данные не передаются другим людям или на сервер. При очистке данных браузера они удаляются. Начальный баланс учебного профиля — 480 бонусов.

На странице заказов до первого оформления показан явно подписанный пример. После оформления отображаются собственные локальные заказы. Кнопка «Следующий этап» демонстрирует статусы, она не получает сведения от курьера. Оплата не списывается. Отправки писем, push-рассылки и сообщений оператору нет: соответствующие формы сохраняют интерес или черновик и прямо сообщают об этом.

Карта — схема для прототипа, а не географический сервис. Она показывает условия зон, но не проверяет точное попадание адреса в зону.

Счётчик старой версии был отдельным числом без состава корзины. Новая корзина начинается с реальных выбранных товаров; неизвестные позиции по старому счётчику не восстанавливаются.

## Промокод

ВТОРАЯ20 (также PIZZA20): при двух и более пиццах скидка 20% на одну пиццу с меньшей ценой. Стоимость доставки определяется после скидки. Размеры и добавки включаются в стоимость. При одной пицце скидка не применяется.

## PWA и офлайн

manifest.json сохраняет запуск в standalone и прежний start_url. Service Worker хранит все 13 экранов, CSS, JS, иконки и фотографии в кеше pizzapoint-app-v3. HTML обновляется из сети, при её отсутствии берётся сохранённая страница. Параметры product.html?id=... не мешают офлайн-открытию карточек. Для неизвестного офлайн-маршрута используется offline.html. Отсутствующий JS или изображение не подменяется HTML. При обновлении удаляются только старые кеши PizzaPoint.

После первого полного открытия онлайн меню доступно без сети. В офлайн-режиме можно просматривать страницы, менять избранное и собирать корзину; оформление блокируется до подключения. Баннер установки появляется при поддержке штатного предложения браузера. В профиле доступна кнопка установки с инструкцией для остальных случаев.

## Проверка

Откройте docs/verification.md: там разделены выполненные автоматические проверки и фактическая проверка в браузере. Дополнительных пакетов для запуска приложения не требуется.

Если установлен Node.js 18 или новее, автоматические проверки запускаются командой npm test. Ставить зависимости не нужно.
